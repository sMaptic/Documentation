### Validation
When importing a file, validation checks ensure that the imported file is valid and meet the criteria outlined in 2.b. These checks are not finalized and still being expanded upon or altered. The validation script first checks if the file exists and is a `.zip` file. Then, the following checks are performed:
```gdscript  
# validation checks
level_data = (func() -> Dictionary:
    var files : Array = reader.get_files()

    # is there exactly 1 level.json file
    var json : Array = files.filter(func(path) -> bool: return path.get_file() == "level.json")
    if json.size() < 1:
        Log.warn("No level.json found in file \"%s\"" % [file_name])
        return {}
    elif json.size() > 1:
        Log.warn("Multiple level.json files found in file \"%s\"" % [file_name])
        return {}

    # does ID exist in level.json
    var temp_data : Dictionary = JSON.parse_string(reader.read_file(json[0]).get_string_from_ascii())
    if not temp_data.keys().has("id"):
        Log.warn("No ID found in level.json for file \"%s\"" % [file_name])
        return {}

    # is ID lower_snake_case
    if temp_data["id"].to_lower() != temp_data["id"]:
        Log.warn("ID is not lower_snake_case for file \"%s\"" % [file_name])
        return {}

    # is level.json in the correct directory
    if not json[0] == "custom_levels".path_join(temp_data["id"]).path_join("level.json"):
        Log.warn("Path of level.json is not \"res://custom_levels/%s/level.json\" for file \"%s\"" % [temp_data["id"], file_name])
        return {}

    # does scene remap matching ID exist in same directory as level.json
    if not json[0].get_base_dir().path_join(temp_data["id"] + ".tscn.remap") in files:
        Log.warn("No scene remap matching ID found for file \"%s\"" % [file_name])
        return {}

    # does scene remap point to real file
    if not Toml.parse(reader.read_file(json[0].get_base_dir().path_join(temp_data["id"] + ".tscn.remap")).get_string_from_ascii())["remap"]["path"] in files.map(func(item) -> String: return "res://" + item):
        Log.warn("No scene binary matching remap found for file \"%s\"" % [file_name])
        return {}

    # successful validation
    temp_data["path"] = at
    temp_data["scene"] = "res://" + json[0].get_base_dir().path_join(temp_data["id"] + ".tscn")
    return temp_data
).call()
```
Currently missing checks:
- Is `.godot` at `res://` and does it contain ONLY required binary files.
- Is the rest of `res://` besides `custom_levels/<map_id>/` and `.godot/` empty? If not, clear those files.

Additionally, when importing a level, the code checks the following to see if any conflicts between packs arise:
- If imported map ID matches existing map ID, ask whether to replace or cancel import.
- If multiple imports share an ID, drop lowest version import.
- If imported `.zip` matches name of existing map `.zip`, add numeric identifier.

If all checks pass, the `.zip` file is copied to the directory `user://custom_levels/`. When a level is deleted, it is removed from this directory, but due to the nature of load_resource_packs(), it will not be freed from memory until the game is closed.
### ID Setup
The current active `level_loader.gd` IDs are stored in the file `user://custom_levels/active_ids.json`. This file is not considered a level by the loader and will not be removed during folder cleanup. When a list refresh is triggered by a successful import/deletion, the following script overwrites the file:
```gdscript  
static func set_active_ids(level_data : Array) -> void:
    # overwrite the active_ids.json file with currently installed map ids and paths
    var id_dict : Dictionary = {}
    for level in level_data:
        id_dict[get_id(level["id"])] = level["scene"]
    var json_content : String = JSON.stringify(id_dict)
    var full_path := LEVELS_PATH.path_join(ID_FILE)
    if FileAccess.file_exists(full_path) or FileAccess.open(full_path, FileAccess.WRITE).store_string(""):
        FileAccess.open(full_path, FileAccess.WRITE).store_string(json_content)
    else:
        Log.error("Could not create or find file \"%s\" at path \"%s\"" % [ID_FILE, LEVELS_PATH])
```
This file is read by `patcher.lua` and appends its values to `LevelName` and `LEVEL_PATHS` in `level_loader.gd` before load time.
### Potential Changes
- In a future update, `level_loader.gd` IDs will hopefully be generated and applied at runtime rather than at load-time. This will eliminate the need for restarts whenever a new map is imported or an old map is removed.
- Currently, a map's `level_loader.gd` ID is identical to the ID provided in `level.json`, plus a `"CL_"` prefix. If namespaces are implemented, however, a namespace identifier would be required also, for example: `CL_CREATURE_MY_MAP`, or `CREATURE/MY_MAP` (if IDs are saved as strings rather than enum keys). This is bulky and unappealing, however it will not be interacted with by the average end user, and prevents many more collisions. This also gives room for maps to use multiple IDs, for example: `CREATURE/MY_MAP/SCENE_1` and `CREATURE/MY_MAP/SCENE_2`.
