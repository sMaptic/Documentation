### Plugin
Currently, no plugin exists for Godot to assist with map development, though this is planned to change. More details to be added at a later date. 
### Known Limitations
Certain features of the Godot engine do not function when loaded during runtime, and below is a (non-comprehensive) list of limitations and features to avoid.
- Autoloads and other load-time hooks are ineffective as packs are always loaded during runtime. Any scripts that rely on load-time behavior to run will fail to execute. Please instead run these scripts at main scene load. If this is required behavior, the GDPatch Lua API allows for pre-load patches to be applied via supporting mod.
- Any features that require editing of project settings cannot be implemented by changing them through the project settings menu. Similarly to autoloads, these are checked at load-time, not runtime. To edit project settings e.g. add a custom keybind, please so programmatically, or use a supporting mod.
- Material overlays on vanilla objects are seemingly inconsistent when loaded in-game. They sometimes work exactly as intended, and other times do not. This is still being investigated.
