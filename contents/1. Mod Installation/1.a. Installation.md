### Mod Loader 
To install the standard mod loader, please first ensure that you have the SNAPTIC Demo downloaded through steam. Then, follow these steps to install and test the loader: 

1. Download the latest release of [GDPatch](https://gdpatch.dev/using/install/) from their website, and ensure you get the version for your operating system. This guide will assume you are using Windows/Wine/Proton. You should receive a file named `gdpatch_loader.dll`.
2. Copy the `.dll` file from your downloads into the SNAPTIC Demo local files root. To find these files, open the game page in your steam library and click "Settings Icon > Manage > Browse local files".
![[browse_local_files_example.png]]
3. Once `gdpatch_loader.dll` is in the same folder as `snaptic.exe`, rename it to `winmm.dll` and start your game. This should create a folder called `GDPatch/` in the same directory.
4. Open this folder, and find the file `config.toml`. Edit this file, and add the following snippet:
```toml
[engine]
encryption_key = "<put your key here>"
```
5. Replace the section within the quotes with the game's encryption key. You can either find this yourself using the GDPatch [pckdec](https://gdpatch.github.io/pckdec/) tool, or ask in the [SNAPTIC Modding](https://discord.gg/PgfbejJ8D) discord server.
### Adding Mods
Now that you have installed the standard mod loader, you can install sMaptic and its dependencies by following these steps:

1. Download the [latest release of SnapticBase](https://github.com/xNasuni/SnapticBase). This is a hard dependency of sMaptic and is not optional to use the mod.
2. Extract the downloaded `.zip` file and place it into the `GDPatch/mods/` folder in your SNAPTIC Demo local files.
3. Start the game and check to see if there is a new "Mods" button on the main menu. If there is not, review the previous steps on this page to ensure you have followed them correctly.
4. Close the game, and download the [latest release of sMaptic](https://github.com/theidiotcreature/sMapticMapLoader/releases/latest). Extract it into your `GDPatch/mods/` folder just like in steps 1 and 2.
5. Start your game again. If you were successful, you should have a "Maps" button on the main menu, and the mod should appear in the "Mods" menu.

**NOTE:** If you are having trouble with installation, please contact @theidiotcreature on discord for assistance. Additionally, this mod is not intended to be used with any version of the game other than the SNAPTIC Demo. Installation with beta/full releases is not supported nor recommended, so any requests for assistance with installing sMaptic to another build will be ignored.
