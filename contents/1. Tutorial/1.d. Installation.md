### WARNING - PLEASE READ
Currently, there is no sandboxing in the latest official release of sMaptic. This means that maps can execute ANY malicious code, and you should be aware of this and ensure that you fully trust any maps that you import. If a map does not have any source files available and contains scripts, treat it with caution and always check that you are installing something safe, regardless of whether you trust the author or whoever sent it to you. 

 Any maps officially endorsed on the sMaptic map index (in whatever form that may take) can be assumed to be safe. Sandboxing is a planned feature for sMaptic which will be implemented before the full 1.0.0 release.
### File Importing
To import a file from outside of the map browser, follow these instructions:

1. Ensure that [GDPatch](https://gdpatch.dev/using/install/) is installed, and both [SnapticBase](https://github.com/xNasuni/SnapticBase) and [sMaptic](https://github.com/theidiotcreature/smapticmaploader) are installed into your mods folder. If you need help with this, join the [SNAPTIC Modding Discord Server](https://discord.gg/PgfbejJ8D). If you have done this successfully, there should be both a Maps and Mods button on the game's main menu.
2. Open the Maps menu and click the import button in the footer, which should open up a file dialog window. Select one or more map zips to import into the game, then click open. Alternatively, open a file browser and drop your zip file(s) into the game window whilst the custom maps menu is open and unobstructed.
3. One or more confirmation/alert dialogs may appear. Please read these carefully! They may require you to overwrite another map if conflicts occur, or inform you that an import has failed. If you would like more details as to why an import may have failed, please check `/GDPatch/output.log` in your game's local files.
4. Press play to test the map! If the map does not load, check logs to see if it is an easily identifiable error. If not, contact the map developer or @theidiotcreature on discord.

**TIP:** If you want to test failed map imports without needing to open `output.log` every time, a setting can be enabled to display a terminal window alongside the game which shows any log updates. This option can be toggled in `/GDPatch/config.toml`, under `[log] console = true`.
### Map Browser
Currently, there is no in-game map browser. This will change in a future release. For now, you can visit the official [sMaptic Map Index](https://smaptic.github.io/MapIndex/) to download maps! More details to be added at a later date.
